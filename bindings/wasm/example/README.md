# Bezier — WebAssembly demo

Interactive multi-curve editor for the [WASM bindings](../README.md). Create, select, and drag
Bezier curves; everything geometric (sampling, length, extrema, offset, intersections,
projection) is computed live in WebAssembly.

## Controls

Mouse:
- **Click** a curve to select it (**Shift**+click adds to the selection; click empty space clears).
- **Drag** a control-point handle of a selected curve to reshape it.
- **Scroll** to zoom in/out (centered on the cursor); **drag empty space** to pan; `0` resets the view.

Keyboard:

| Key | Action |
| --- | --- |
| `N` | New curve — click to place control points, `Enter` to finish, `Esc` to cancel |
| `F` | Freehand — drag to draw a stroke, release to fit a curve |
| `Del` / `Backspace` | Delete selected curves |
| `↑` / `↓` | Raise / lower order of selected |
| `O` + `↑`/`↓` | Increase / decrease offset-curve distance (hold `O`) |
| `B` | Toggle bounding boxes |
| `E` | Toggle extrema |
| `I` | Toggle intersections (between curves and self-intersections) |
| `P` | Toggle projection — tangent / normal at the cursor |
| `J` | Fit-join exactly two selected curves into one |
| `H` / `?` | Toggle the in-app help overlay |
| `R` | Reset the scene |

## Run locally

```bash
# from bindings/wasm — build the WASM module + TS package, then stage the demo
source ~/emsdk/emsdk_env.sh   # or wherever emsdk lives
emcmake cmake -S . -B build && cmake --build build   # -> dist/bezier_wasm.{mjs,wasm}
npm install && npm run build && npm run bundle:demo   # -> example/dist/

# serve (any static server; ES modules need http, not file://)
python3 -m http.server -d example 8080
# open http://localhost:8080
```

`example/dist/` is generated by `bundle:demo` (git-ignored). Only `index.html`, `demo.js`,
and this README are tracked.
